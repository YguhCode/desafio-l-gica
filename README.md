Classificador de Nível de Herói

Esse projeto foi desenvolvido durante meus estudos de programação, baseado em um desafio proposto pela DIO.

O desafio originalmente era feito em JavaScript, mas decidi desenvolver a minha própria versão em Java para praticar a linguagem e reforçar conceitos de lógica de programação.

📖 Sobre o projeto

A ideia do programa é criar um herói, gerar uma quantidade de XP e, através dessa pontuação, definir o nível do personagem.

Dependendo da quantidade de experiência, o herói pode receber classificações como:

Ferro
Bronze
Prata
Ouro
Platina
Ascendente
Imortal
Radiante

🛠️ O que pratiquei nesse projeto

Durante o desenvolvimento, coloquei em prática alguns conceitos básicos e importantes:

Variáveis
Entrada de dados com Scanner
Geração de números aleatórios com Random
Operadores lógicos e relacionais
Estruturas condicionais (if e else if)
▶️ Exemplo de execução
Digite o nome do seu herói: Arthur

Nome: Arthur
XP: 7342


O Herói de nome Arthur está no nível de Platina
